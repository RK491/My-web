# Personal Bio Website

A modern, dynamic personal bio website with a password-protected admin panel. Built with Node.js, Express, and Vanilla JS.

## Features
- **Dynamic Frontend:** Updates instantly without page reloads.
- **Admin Panel:** Add/Edit/Delete links and update bio at `/admin`.
- **Animations:** Floating profile picture and hover effects.
- **Lightweight:** Uses a JSON file for storage (no complex database setup).
